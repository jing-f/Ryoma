# 用户注册页面实验
## 作业内容
本次实验制作用户注册页面，综合使用HTML语义化标签、列表、表格、表单相关标签，搭配JS实现表单提交监听，在控制台打印表单数据。

## 使用标签
1. 语义化标签：`<header>`、`<main>`、`<footer>`
2. 表单标签：`<form>`、`<input>`、`<label>`、`<select>`、`<option>`、`<textarea>`、`<button>`
3. 表格标签：`<table>`、`<thead>`、`<tbody>`、`<tr>`、`<th>`、`<td>`，使用`colspan`合并单元格
4. 列表标签：无序列表`<ul>`、有序列表`<ol>`、定义列表`<dl>`

## 遇到困难与解决方法
1. 困难：label两种用法混淆。解决：一种用for+id关联，另一种直接包裹input。
2. 困难：表单提交页面自动刷新。解决：JS中使用`e.preventDefault()`阻止默认提交行为。
3. 困难：获取表单全部数据。解决：使用FormData快速收集表单内所有带name属性控件的值。

## 运行方式
使用VSCode打开，Live Server插件启动，浏览器F12打开控制台，提交表单查看输出数据。
